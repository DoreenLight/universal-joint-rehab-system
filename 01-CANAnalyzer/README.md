# CANAnalyzer — CAN 分析仪资料

USBCAN / CANalyst-II 分析仪的随附官方资料，用于 CAN 总线报文收发、波特率侦测与二次开发，与电机板 CAN 通信调试配套。

## 内容

| 位置 | 内容 |
| --- | --- |
| `说明文档目录/` | 中文说明书与附件 1–23（产品说明、驱动安装、接口函数库、DBC 协议解析、ID 对齐、多卡同机、曲线绘制等）、英文 `Manual/`、`产品规格书V2.2/` |
| `二次开发库文件/` | `ControlCAN` 库：`win32(32bit)` / `x64(64bit)` 动态库与导入库、For VC / VB / Delphi 头文件、For LabVIEW8.6 封装；接口函数库说明书 |
| `硬件驱动程序/` | USB 驱动安装工具与安装/卸载说明书 |
| `调试工具/` | 原厂 USB-CAN Tool；周立功兼容工具 CANPro V1.50、CANTest、ZOPC_Server（含协议分析插件） |
| `入门指引.pdf` | 快速上手 |
| `二次开发示例源代码下载地址.txt` | 官方示例源码下载链接 |
| `保修与免责说明V2.03.txt` | 厂商说明 |

## 注意

- 本目录为第三方资料，著作权归原厂所有，仅供内部调试参考。
- 工具与驱动为 Windows 程序（`.exe` / `.dll` / `.lib` / `.llb`），在 macOS 上无法直接运行。
