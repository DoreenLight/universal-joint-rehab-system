# UART3 电机控制协议 v2.6

## 物理层

| 参数 | 值 |
|------|-----|
| 接口 | UART3 (PC10-TX, PC11-RX) |
| 波特率 | 230400, 8N1 |
| 帧间隔 | IDLE 检测 (帧间 ≥ 1ms) |

---

## 帧格式

```
┌────────┬────────┬────────┬──────┬────────────┬──────────┬──────────┐
│ SYNC_H │ SYNC_L │  LEN   │ CMD  │  PAYLOAD   │   SUM    │   END    │
│  0x6C  │  0x67  │  1B    │  1B  │  0~250 B   │   1B     │  0xED    │
└────────┴────────┴────────┴──────┴────────────┴──────────┴──────────┘

SUM = (LEN + CMD + PAYLOAD各字节之和) & 0xFF
END = 0xED  (帧尾, 防止 float 数据误同步)

最小帧: 6B, 最大帧: 256B
```

## 命令

### 上位机 → MCU

| CMD | 名称 | 载荷 | 说明 |
|-----|------|------|------|
| `0x01` | IO_WRITE | `[id][val]` | IO 信号 |
| `0x02` | FLOAT_WRITE | `[id][val×4B_LE]` | 单个浮点 |
| `0x03` | BATCH_WRITE | `[cnt][(id)(val×4B_LE)]*` | 批量浮点 |
| `0x84` | PING | 空 | 心跳, MCU 自动 ACK |
| `0x85` | FLASH_SAVE | 空 | PID/速度参数存入 Flash |

| CMD | 名称 | 载荷 | 说明 |
|-----|------|------|------|
| `0x81` | TELEMETRY | `[cnt][(id)(val×4B_LE)]*` | 遥测, ~20Hz, 10 float/帧 |
| `0x83` | ACK | `[ack_cmd]` | 应答 |

## 康复被动控制

设置参数后单击启动，电机在 min/max 之间梯形轨迹循环往复，完成后自动回到 0°。

### 状态机

IDLE -->(start) FORWARD -->(at max) BACKWARD -->(at min)--> ...
  ^                                 |
  +-------(more cycles)-------------+
                              (done)
                                 v
                          RETURN -->(at 0) DONE (auto stop)

### Motor1 康复

| 步骤 | 操作 | 指令 |
|------|------|------|
| 1 | 设模式=位置 | `6C 67 02 01 02 00 05 ED` |
| 2 | 设 min=-10 | `6C 67 05 02 08 00 00 20 C1 XX ED` |
| 3 | 设 max=30 | `6C 67 05 02 09 00 00 F0 41 XX ED` |
| 4 | 设 cycles=5 | `6C 67 05 02 0A 00 00 A0 40 XX ED` |
| 5 | 启动康复 | `6C 67 02 01 08 01 0C ED` |
| 6 | 停止康复 | `6C 67 02 01 08 02 0D ED` |

### Motor2 康复

| 步骤 | 操作 | 指令 |
|------|------|------|
| 1 | 设 min=-20 | `6C 67 05 02 1A 00 00 A0 C1 XX ED` |
| 2 | 设 max=40 | `6C 67 05 02 1B 00 00 20 42 XX ED` |
| 3 | 设 cycles=3 | `6C 67 05 02 1C 00 00 40 40 XX ED` |
| 4 | 启动康复 | `6C 67 02 01 09 01 0D ED` |

## 主动康复控制 (Motor1)

T 型波为虚拟轨迹(仅给患者看的引导线)，电机仅在力矩超限时屈服转动。

### 原理

- **T 型波**: 在极限角1和极限角2之间梯形往复，两端各停 t 秒，通过遥测 index 16 上传
- **电机运动**: 仅当 |Mx| > Tmax 时转动
- **力控公式**: sudu = -sign(Mx) * (|Mx| - Tmax) / k
- 电机以速度模式工作，力矩在阈值内时保持静止

### 操作流程

| 步骤 | 操作 | 指令 |
|------|------|------|
| 1 | 设速度=30 |  |
| 2 | 设极限1=-30 |  |
| 3 | 设极限2=30 |  |
| 4 | 设停顿=2s |  |
| 5 | 设 Tmax=5 |  |
| 6 | 设刚度 k=10 |  |
| 7 | 启动 |  |
| 8 | 停止 |  |

## 校验和 (Python)

```python
import struct

def calc_checksum(len_cmd_payload):
    return sum(len_cmd_payload) & 0xFF

def build_io_frame(io_id, val):
    payload = bytes([io_id, val])
    body = bytes([len(payload), 0x01]) + payload  # LEN + CMD + PAYLOAD
    return bytes([0x6C, 0x67]) + body + bytes([calc_checksum(body)]) + bytes([0xED])

def build_float_frame(float_id, value):
    payload = bytes([float_id]) + struct.pack('<f', value)
    body = bytes([len(payload), 0x02]) + payload
    return bytes([0x6C, 0x67]) + body + bytes([calc_checksum(body)]) + bytes([0xED])

# 例: 启动 motor1
frame = build_io_frame(0x01, 1)
# → b'\x6C\x67\x02\x01\x01\x01\x05\xED'
```
