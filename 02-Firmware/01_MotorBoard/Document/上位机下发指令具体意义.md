## 上位机设计建议

主动、被动输入框统一放置在窗口左侧。

上位机选择固定模式后，不相关的输入框变灰禁用。

| 模式 | 可用指令 |
|------|---------|
| 掌屈/背屈 | 电机1 启停 + 角度/速度/Kp/Ki |
| RS00 运控 | 电机2 启停 + 模式 + 运控参数 |





# 上位机下发指令 (UART2)

## UART2 协议帧格式

```
帧长: 14 字节 (固定)

┌────────┬────────┬────────┬────────┬────────┬────────────────────┬──────────┐
│ HEAD1  │ HEAD2  │  ADDR  │  CMD1  │  CMD2  │      DATA[8]       │ CHECKSUM │
│  0x6D  │  0x6A  │  1B    │  1B    │  1B    │       8B           │   1B     │
└────────┴────────┴────────┴────────┴────────┴────────────────────┴──────────┘

CHECKSUM = (ADDR + CMD1 + CMD2 + DATA[0] + ... + DATA[7]) & 0xFF
ADDR 固定为 0x01
```

## 详细指令

### 1. 电机1 启动/停止 (CMD1=0x01)

| 字段 | 值 |
|------|-----|
| 帧头 | `6D 6A` |
| ADDR | `01` |
| CMD1 | `01` |
| CMD2 | `01` |
| DATA[0] | `01` = 启动, `00` = 停止 |
| DATA[1..7] | `00` |

**启动**: `6D 6A 01 01 01 01 00 00 00 00 00 00 00 02` (CHECK=sum[1:]=0x02)

**停止**: `6D 6A 01 01 01 00 00 00 00 00 00 00 00 01`

### 2. 电机1 浮点命令 (CMD1=0x06)

浮点数使用 `memcpy` 小端序 IEEE 754 编码。

DATA 区分为两部分：
- `DATA[0..3]` (data_bytes): 第一个 float
- `DATA[4..7]` (data_bytes_ext): 第二个 float (备用)

| CMD2 | 功能 | 使用字段 | 写入变量 |
|------|------|---------|---------|
| 0x01 | 角度 | data_bytes → float | `my_Order_mode.motor1_jiaodu` |
| 0x02 | 速度 | data_bytes → float | `my_Order_mode.motor1_sudu` |
| 0x03 | 电流 | data_bytes → float | `my_Order_mode.motor1_dianliu` |
| 0x04 | Kp | data_bytes → float | `my_Order_mode.motor1_kp` + `Control_P_PID.kp` |
| 0x05 | Ki | data_bytes → float | `my_Order_mode.motor1_ki` + `Control_P_PID.ki` |

**例: 设置角度为 1.5°**

- 1.5f 小端序: `00 00 C0 3F`
- 帧: `6D 6A 01 06 01  00 00 C0 3F  00 00 00 00  XX`

### 3. 电机2 整数命令 (CMD1=0x11) — RS00 CAN 电机

| CMD2 | 功能 | DATA[0] | 说明 |
|------|------|---------|------|
| 0x01 | 使能/停止 | 0x01=使能, 0x00=停止 | `RS00_Enable()` / `RS00_Stop()` |
| 0x02 | 运行模式 | 1=运控, 2=位置, 3=速度, 5=CSP | `RS00_SetRunMode()` |
| 0x03 | 机械零点 | 无 | `RS00_SetZeroPosition()` |
| 0x04 | 清除故障 | 无 | `RS00_StopAndClearError()` → `RS00_Enable()` |

### 4. 电机2 浮点命令 (CMD1=0x16) — RS00 高级控制

浮点数使用 `memcpy` 小端序 IEEE 754 编码。

| CMD2 | 功能 | 使用字段 | 说明 |
|------|------|---------|------|
| **0x01** | 运控指令 ★ | data_whole (8B) | 多参数混合编码，见下方 |
| 0x02 | 速度模式 | data_bytes → speed, data_bytes_ext → cur_limit | `RS00_WriteParamFloat(0x700A)` |
| 0x03 | 力矩指令 | - | 预留，暂不处理 |
| 0x04 | 设置 Kp | data_bytes → float | `RS00_WriteParamFloat(0x701E)` |
| 0x05 | 设置 Kd/Ki | data_bytes → float | `RS00_WriteParamFloat(0x7020)` |
| 0x06 | 电流限制 | data_bytes → float | 仅 printf，暂不执行 |

#### CMD2=0x01 运控指令混合编码 (parse_host_dynamic_params)

8 字节混合打包 5 个参数：

| 参数 | 源位 | 范围 | 编码 |
|------|------|------|------|
| position_ref | DATA[0:1] uint16 | -12.57 ~ +12.57 | `(u16/65535)*25.14 - 12.57` |
| velocity_ref | DATA[2] + DATA[3]高4位 (12bit) | -33.0 ~ +33.0 | `(u12/4095)*66.0 - 33.0` |
| Kp | DATA[3]低4位 + DATA[4] (12bit) | 0 ~ 500 | `(u12/4095)*500` |
| Kd | DATA[5] + DATA[6]高4位 (12bit) | 0 ~ 5 | `(u12/4095)*5` |
| torque_ref | DATA[6]低4位 + DATA[7] (12bit) | -14.0 ~ +14.0 | `(u12/4095)*28.0 - 14.0` |
